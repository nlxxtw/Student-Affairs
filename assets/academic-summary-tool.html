规则使用与计算规则展开查看上传要求、计算口径和缺失数据处理方式。⌄

一、使用范围与上传要求

  1. 需上传第 1 学期综测、第 2 学期综测、学业成绩、课程成绩和《汇总》名单五份表格，五份文件可以使用不同格式。
  2. 以学号匹配个人数据；《学业成绩》和《汇总》均须包含“学号、姓名、班级”，其他来源表可不含班级。
  3. 《汇总》是唯一统计名单；综测、学业成绩和课程成绩中多出的学生会在生成时弹窗列出学号、姓名和来源，确认后忽略，不补充进结果。最终按班级、学号排序。
  4. 《汇总》名单内出现重复学号，或名单内学生在来源表中重复、姓名不一致、必需列缺失时，会提示修正后再生成；名单外学生不参与核对。

二、综测与班级排名

  1. “综测1”“综测2”分别读取两份综测表的“综测总分”，缺失记录或空白分数在对应输出字段中按 0 分显示。
  2. “综测（平均）”按实际有成绩的学期数计算：两学期有成绩时除以 2，仅一学期有成绩时按（已有成绩 + 0）÷ 1，两个学期都缺失时为 0。
  3. 综测排名仅在《汇总》名单的同班级学生中比较，按平均分由高到低采用同分同名次、后续跳位规则，例如 3、3 后为 5。
  4. 综测排名显示为“名次/班级总人数”，百分比为名次 ÷ 班级总人数。

三、学业成绩与课程成绩

  1. “学分加权平均分”“平均学分绩点”读取《学业成绩》对应字段，缺失记录或空白分数按 0 分。
  2. 学分加权平均分排名、平均学分绩点排名均在《汇总》名单的同班级学生中按对应实际分数由高到低重新计算，不读取、不采用来源表给定排名；同分同名次、后续跳位。
  3. “最低分”为《课程成绩》中该生所有有效成绩的最低值；没有课程成绩时按 0 分，“最低分科目”留空。
  4. “补考科目”取课程性质为“补考一”的课程；“重修科目”取课程性质为“重修”或“重修补考”的课程。

四、格式、缺失数据与持久化

  1. 综测1、综测2、综测平均、学分加权平均分、平均学分绩点保留 2 位小数；三个排名百分比按百分比保留 2 位；最低分显示为整数。
  2. 《汇总》名单中的学生无论在一个、多个或全部来源表缺失，都保留在结果中；对应缺失字段统一按 0 分处理并参与班级排名，不再弹窗要求选择处理方式。
  3. 原始上传文件仅在本次页面使用，刷新或退出后清除；每次生成的历史记录保存到系统数据库，输出文件进入加密附件库，只有手动删除历史记录才会清除。

提示：来源表中的排名列不再参与计算；即使未提供学分加权平均分排名或平均学分绩点排名列，也可以正常生成。加密、损坏或采用少数 WPS 专有存储的 et/ett 文件仍需在 WPS 中另存为 xlsx。
