一、文件选择与支持范围

  1. 每次选择 2–100 个同类 Excel 文件，可选择整个文件夹，也可一次多选文件。
  2. 支持 .xlsx、.xlsm、.xlsb、.xls（含 Excel 5.0/95/97–2003 老版本）、.xltx、.xltm、.xlt、WPS .et/.ett、.ods/.fods/.ots、Excel 2003 XML、.csv 与 .txt（制表符分隔）。CSV/TXT 自动识别 UTF-8、GBK、UTF-16 编码，中文不乱码。
  3. 含宏文件只读取已保存的单元格结果，不执行或保留宏；密码保护、严重损坏或仅含外部连接而未保存结果的文件无法合并。
  4. 单文件不超过 50MB，总输入不超过 150MB；文件只在当前浏览器本机处理，不会上传网络。

二、表头与数据范围

  1. “自动识别表头”会在设定的前若干行中寻找标题；识别不准确时，可逐文件修改表头行后重新识别。
  2. “指定标题行”按输入行号读取标题；标题上方内容不合并，数据从标题下一行开始。
  3. “末尾几行不合并”按每个文件末尾的非空数据行分别扣除；完全空白行始终忽略。
  4. 数据区中与表头完全相同的行（常见于把以前的合并结果再次混入）会被自动剔除并提示。

三、表头差异与列映射

  1. 默认以第一个文件作为标准表头，也可将其他文件设为标准，并调整最终输出列顺序和名称。
  2. 列名不完全一致时，会按常见同义词（如“姓名/学生姓名”“联系电话/手机号”“班级/行政班级”）自动建议映射，合并前仍需人工核对。
  3. 列名或列顺序不一致时会标出具体文件和问题列；必须核对列映射后才能合并。
  4. 某个文件确实缺少标准列时，应选择“该文件此列留空”，避免把数据对应到错误列。

四、AI 辅助边界

  1. AI 仅接收表头名称、行数等统计元数据，不发送任何单元格数据。
  2. AI 建议仅作辅助：智能映射给出来源列建议，表头规范给出输出列名建议，合并前核查输出风险报告；应用前均可人工确认。
  3. 需在系统「AI 智能 → API配置」配置模型并开启“Excel 合并智能助手”后方可使用；未配置不影响本机合并功能。

五、内容格式、输出与历史

  1. 建议保留 Excel 显示内容，以避免学号等编号丢失前导零；隐藏行是否合并按页面勾选项执行；合并单元格会按左上角的值自动填充后再合并。
  2. 公式只读取文件中已保存的计算结果；若发现未缓存公式，请先用 Excel/WPS 计算并保存。
  3. 可选合并后去重（整行相同或按关键列判断，保留首次出现或仅标记）、按文件分工作表和 CSV 输出。
  4. Excel 结果包含“合并结果”和“合并说明”两个工作表；运行记录保存到系统数据库，结果文件进入加密附件库，可再次下载，只有手动删除历史记录才会清除。

提示：合并前请确认各文件属于同一类表格，并检查所选工作表、表头行和列映射。不要把以前生成的“Excel合并结果.xlsx”与原始文件放在同一待选文件夹中重复合并。
