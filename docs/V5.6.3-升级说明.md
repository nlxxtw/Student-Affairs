# 数智学工 V5.5.9 → V5.6.3 升级说明

升级日期：2026-10-26
源版本：V5.5.9（本目录）　目标版本：V5.6.3（H:\Downloads\数智学工V5.6.3）

## 一、本次新增 / 升级的功能

### V5.6.3（2026-10-25）
- **数据中心（新模块）**：`data-center-module.js` + `data-center-service.js`，侧边栏新增"数据中心"入口。支持模块清单、资源/模板管理、历史记录、批量选择转移；服务器新增 `/api/data-center/*` 接口。
- **模板中心**：学院、专业、年级、招生类别、**培养层次**、班级、区位与楼栋的基础数据导入模板（xlsx 下载 + 批量导入）。
- **培养层次统一**：原"学历"统一并入"培养层次"可维护字典，学生/班级导入、模板、批量修改统一读取该字典，`学历`作为导入别名兼容。
- **党建跟踪表快捷导入 + 发展历程**：党建跟踪支持表格快捷导入，新增发展历程视图。
- **附件/备份校验和**：附件与备份增加完整性校验和。
- **全系统 UI 优化**。

### V5.6.2
- **学历字典可维护**：基础数据新增学历字典及高中建议项；学生新增/编辑/批量修改/班级选项统一读取字典；导入允许自定义学历，明确填写的学历不被班级默认值覆盖。
- **辅导员成长档案新增"培训"成果类型**（录入、导入、筛选、统计、Excel/Word 导出）。
- 概览类别分布默认"全部年度含归档"，可独立筛选年度与归档范围；成果台账通用分页；成果详情支持图片/PDF/音视频支撑材料预览（新窗口查看、原名下载）。

### V5.6.1
- 修复学生编辑修改学号时"关联先写导致保存失败"；学号/姓名更正后，资助、谈话、住宿、请销假、考勤、就业、花名册、学业等结构化关联在同一事务内同步；同名学生按学号隔离，目标学号被占用时阻止合并并整批回滚。
- 导入撤销历史、回收站身份关联同步；身份保护记录纳入备份。
- **辅导员成长档案新增"聘书"成果类型**。

### V5.6.0
- **学生新增"借读"学籍状态**：学籍状态由 7 类扩展为 8 类（在校、借读、休学、退学、转出、毕业、延期毕业、其他），驾驶舱统计同步，状态页签支持横向滚动；借读不计入仅限在校生的住宿/请假/班委/统计。
- **辅导员成长档案新增"资格证书"分类**。
- 启动及本机会话失效后统一返回主页。
- 学业情况（公用版）新增使用与操作手册下载入口（手册已随包：`assets/academic-public-user-manual.docx`）。
- 单条新增/修订成绩支持**绩点自动换算**（自定义映射优先，手动修改后保留，可恢复自动）；课程成绩/补考/重修统一"成绩备注"（正常考试/缓考/旷考/作弊）。
- 单条新增四类学业数据免填考试批次，内部按考试日期/学期保留稳定身份。

## 三、刻意保留（未覆盖）

| 文件/目录 | 原因 |
|---|---|
| `license-config.json` | 保持本地 `enabled:false`。V5.6.3 原包为 `enabled:true`+线上 apiUrl，直接覆盖会触发授权校验并可能锁定业务页 |
| `update-config.json` | 保持本地 `enabled:false`，不启用自动更新 |
| `data/`（含 `workbench.db`、附件、`portable-data-key.json`） | 本地真实业务数据，绝不覆盖 |
| `backups/`、`updates/`、`runtime/` | 运行时/备份目录 |
| `.gitignore`、`.git/` | 版本控制 |
| `cloud/`、`tests/` | 开发者工具/测试，非运行必需 |

## 四、生效与回滚

**生效**：需重启服务（旧进程仍在内存运行旧代码）。
1. 关闭：`关闭数智学工.vbs`
2. 启动：`启动数智学工.vbs`
3. 浏览器强制刷新（Ctrl+F5）

首次启动会执行 V5.6.x 数据库迁移（借读状态、培养层次字典、数据中心表等），请勿在迁移过程中强杀进程。

**回滚**：源码备份在 `源码备份/V5.5.9-before-V5.6.3-20261026/`（含被覆盖源码 + workbench.db 快照）。
如需回滚：关闭服务 → 用备份覆盖回对应文件 → 从备份恢复 `data/workbench.db*` → 重启。
